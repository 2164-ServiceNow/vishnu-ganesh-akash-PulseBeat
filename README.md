# Project Title: Spotify Web API Explorer

**Project Description:**  
PulseBeeT is a robust web application designed to interact with Spotify's streaming service. The application enables users to retrieve metadata about their favorite artists, albums, and tracks, manage playlists, control playback, and explore Spotify's vast music catalog. This project demonstrates the integration of RESTful APIs to create engaging and interactive user experiences.

---

## **Technologies Used:**

- **Frontend:**
  - HTML5
  - CSS3
  - JavaScript (ES6+)
  - Angularjs (Version 1.8.x)
  - Node.js (Version: ^18.0.0)

- **API:**
  - [Spotify Web API](https://developer.spotify.com/documentation/web-api/)

- **Authentication:**
  - OAuth 2.0 (Spotify Authorization Code Flow)

- **Other Tools:**
  -  FetchApi
  

## **User Stories:**

1. **Authentication:**  
   As a user, I want to log in with my Spotify account so that I can access personalized features.

2. **Search:**  
   As a music enthusiast, I want to search for songs, albums, and artists so that I can discover new music.

3. **Track Details:**  
   As a listener, I want to view detailed metadata about any track, album, or artist so that I can better understand the content.

4. **Playback Control:**  
   As a user, I want to play, pause, and skip tracks directly from the app so that I can have full control over my listening experience.

5. **Playlist Management:**  
   As a playlist curator, I want to create and manage my playlists so that I can organize my favorite music.

6. **Recommendations:**  
   As a music lover, I want to see personalized recommendations so that I can discover new tracks based on my listening habits.

7. **Top Tracks:**  
   As a Spotify user, I want to view my top tracks and artists so that I can reflect on my listening trends.

8. **Listening History:**  
   As a user, I want to see my recently played tracks so that I can revisit them anytime.

9. **Track Relinking:**  
   As a listener, I want unavailable tracks to be automatically replaced with playable versions so that I can enjoy uninterrupted playback.

10. **Secure Logout:**  
    As a user, I want to securely log out of my account so that my data and credentials remain safe.
